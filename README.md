# حزمة بوابات الدفع الإلكتروني العُمانية لمتجر باجيستو
# Bagisto Omani Payment Gateways Package (via iFrame)

حزمة احترافية متكاملة وقابلة لإعادة الاستخدام بنسبة 100% لإضافة بوابات الدفع الإلكتروني المعتمدة في سلطنة عُمان إلى متاجر **Bagisto** (الإصدار 2.x وما بعده) ومبنية على إطار عمل **Laravel**. تدعم الحزمة **4 بوابات دفع رئيسية** معتمدة ومتوافقة مع معايير البنك المركزي العُماني (CBO) وتعمل جميعها بنظام التضمين الآمن **iFrame** التفاعلي مع دعم وضع المحاكاة الذكي (Simulation Mode) للتجربة الفورية.

---

## 🌟 بوابات الدفع المدعومة (4 بوابات)

| البوابة | طريقة الربط والـ iFrame | شبكات البطاقات المدعومة |
| :--- | :--- | :--- |
| **1. ثواني باي (Thawani Pay)** | Checkout Session API + iFrame مدمج | محفظة ثواني، بطاقات عمان نت (OmanNet)، فيزا، ماستركارد |
| **2. بنك مسقط SmartPay (MPGS)** | Mastercard Payment Gateway Services Hosted iFrame | بطاقات الخصم المباشر لبنك مسقط، فيزا، ماستركارد، عمان نت |
| **3. أموال باي (AmwalPay)** | Amwal SmartBox iFrame + Secure Hash | شبكة بطاقات الخصم المباشر الوطنية (عمان نت OmanNet)، فيزا، ماستركارد |
| **4. باي موب عمان (Paymob Oman)** | Payment Key Token + Hosted iFrame | بطاقات عمان نت المحلية، البطاقات الدولية، المحافظ الرقمية |

## ✨ المميزات الرئيسية

- **تضمين iFrame تفاعلي وسلس**: تجربة مستخدم عصرية بدون مغادرة المتجر مع مؤشرات تحميل وشارات أمان مشفرة (256-bit SSL).
- **اتصال آمن عبر postMessage**: استماع آمن لرسائل الإتمام والتحدي الأمني (3D Secure 2.0 / OTP) بين الـ iFrame والنافذة الرئيسية.
- **وضع المحاكاة الذكي (Interactive Simulation Mode)**: إمكانية تجربة واختبار دورة الدفع كاملة وإنشاء الطلبات والفواتير فورياً بدون الحاجة لحساب بنكي أو مفاتيح تجارية حقيقية.
- **التوافق الكامل مع واجهات API الحقيقية**: دعم بيئات الاختبار (Sandbox / UAT) والإنتاج (Live / Production) بمجرد إدخال مفاتيح التاجر.
- **إدارة الطلبات والفواتير التلقائية**: إنشاء الطلب (Order) بحالة `Processing`، وتوليد الفاتورة (Invoice) بحالة `Paid`، وتسجيل المعاملة في `OrderTransaction` تلقائياً فور نجاح الدفع.
- **تسجيل وتدقيق المعاملات (Audit Trail)**: جداول مخصصة لتسجيل حركات الدفع ورموز الجلسات وإشعارات الويب هوك (Webhooks).
- **دعم ثنائي اللغة بالكامل**: ملفات ترجمة كاملة باللغتين العربية والإنجليزية (`ar`, `en`).
- **بنية معمارية نظيفة (Clean Architecture)**: فصل تام بين طبقة العرض والخدمات والمتحكمات والعقود (Contracts).

## 📦 التثبيت والإعداد السريع

### 1. إضافة الحزمة إلى المشروع

الحزمة موجودة في مسار الحزم المخصص:
```bash
packages/NumbersNebula/OmanPayments
```

في ملف `composer.json` الرئيسي للمتجر، تأكد من إضافة مسار الـ PSR-4:
```json
"autoload": {
    "psr-4": {
        "Webkul\\OmanPayments\\": "packages/NumbersNebula/OmanPayments/src"
    }
}
```

### 2. تسجيل مزود الخدمة (Service Provider)

أضف مزود الخدمة إلى مصفوفة المزودين في `bootstrap/providers.php`:
```php
use NumbersNebula\OmanPayments\Providers\OmanPaymentsServiceProvider;

return [
    // ... مزودات الخدمات الأخرى
    OmanPaymentsServiceProvider::class,
];
```

### 3. تحديث خريطة الـ Autoload وتشغيل الترحيلات

```bash
composer dump-autoload
php artisan migrate
```

ستقوم الترحيلات بإنشاء الجداول التالية تلقائياً:
- `oman_payment_transactions` (سجل المعاملات العمانية وحالتها)
- `oman_payment_webhooks` (سجل إشعارات الويب هوك)

## ⚙️ التكوين من لوحة تحكم المتجر (Bagisto Admin)

توجه إلى لوحة التحكم:
**لوحة الإدارة (Admin) ➔ الإعدادات (Configure) ➔ المبيعات (Sales) ➔ طرق الدفع (Payment Methods)**

ستجد قسماً مخصصاً لكل بوابة من البوابات الأربع:

### 1. بوابة ثواني (Thawani Pay)
- **الحالة (Status)**: تفعيل / تعطيل
- **وضع المحاكاة (Simulation Mode)**: نعم للتجربة الفورية، لا للاستدعاء الحقيقي
- **وضع البيئة التجريبية (Sandbox)**: تفعيل بيئة UAT
- **المفتاح العام (Publishable Key)**
- **المفتاح السري (Secret Key)**

### 2. بنك مسقط SmartPay (MPGS)
- **الحالة (Status)**: تفعيل / تعطيل
- **معرف التاجر (Merchant ID)**
- **كلمة مرور الـ API (API Password)**
- **خادم البوابة (Gateway Host)**: الافتراضي `bankmuscat.gateway.mastercard.com`
- **إصدار الواجهة (API Version)**: الافتراضي `100`

### 3. أموال باي (AmwalPay - OmanNet)
- **الحالة (Status)**: تفعيل / تعطيل
- **معرف التاجر (Merchant ID)**
- **معرف النقطة (Terminal ID)**
- **المفتاح السري (Secret Key)** لإنشاء Secure Hash (HMAC-SHA256)

### 4. باي موب عمان (Paymob Oman)
- **الحالة (Status)**: تفعيل / تعطيل
- **مفتاح الواجهة (API Key)**
- **معرف التكامل (Integration ID)**
- **معرف الـ iFrame (iFrame ID)**
- **المفتاح السري لـ HMAC (HMAC Secret)**

## 🧪 التجربة والاختبار الفوري

الحزمة تأتي مجهزة بوضع **المحاكاة التفاعلية (Simulation Mode)** المفعل افتراضياً:

1. أضف أي منتج إلى سلة التسوق في المتجر.
2. انتقل إلى شاشة إنهاء الطلب (Checkout).
3. اختر أي بوابة عمانية من البوابات الأربع:
   - **ثواني باي (Thawani Pay)**
   - **بنك مسقط SmartPay (MPGS)**
   - **أموال باي (AmwalPay - عمان نت)**
   - **باي موب عمان (Paymob Oman)**
4. انقر على **تأكيد الطلب**؛ سيتم فتح صفحة الـ **iFrame** التفاعلية المخصصة للبوابة مباشرة.
5. انقر على زر **تأكيد الدفع (محاكاة ناجحة)** داخل الـ iFrame.
6. سيقوم النظام فوراً بالتحقق من المعاملة، وإنشاء الطلب، وتوليد الفاتورة المسددة، وتوجيه العميل لصفحة نجاح الطلب مع رقم الطلب الجديد!

## 🧪 تشغيل الاختبارات الآلية (Automated Tests)

الحزمة تحتوي على حزمة اختبارات برمجية تغطي جميع البوابات والـ iFrame والتحقق ودورة الطلب الكاملة:

```bash
php artisan test packages/NumbersNebula/OmanPayments/tests
```

ستتحقق الاختبارات من:
- تسجيل وتكامل البوابات الأربع في إعدادات باجيستو.
- إنشاء الجلسات وعناوين الـ iFrame.
- التحقق من العمليات المكتملة.
- استجابة واجهات المحاكاة برمز `HTTP 200`.
- استقبال ومعالجة إشعارات الويب هوك.
- دورة الدفع الكاملة (End-to-End Checkout) من السلة حتى الفاتورة.

## 🛡️ الأمان والامتثال

- **التوافق مع البنك المركزي العُماني (CBO)**: توجيه بطاقات الخصم المباشر المحلية عبر شبكة عمان نت وتفعيل المصادقة الثنائية 3DS OTP.
- **تأمين بروتوكول postMessage**: تقييد ومعالجة بيانات الدفع والتأكد من أصل المصدر والتحقق المزدوج من السيرفر قبل اعتماد أي طلب.
- **حماية الويب هوك (Webhooks)**: التحقق من التوقيع الرقمي والتجزئة الآمنة (HMAC-SHA256) قبل معالجة أي إشعار خارجي.
